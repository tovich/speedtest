# Speedtest — свой сервер для проверки скорости интернета

Один контейнер на Go (~15 МБ) с фронтендом без фреймворков.
Показывает IP посетителя, страну, город, провайдера (ASN) и меряет:

| Параметр | Как меряется |
|---|---|
| Загрузка (средняя и пиковая) | 6 параллельных HTTP-потоков несжимаемых данных, 10 с, первые 1,5 с (разгон TCP) отбрасываются |
| Отдача (средняя и пиковая) | 4 параллельных POST-потока по 8 МБ случайных данных, 10 с |
| Пинг в покое (медиана/мин/ср/макс) | 20 эхо-сообщений по WebSocket |
| Джиттер, σ | средняя разница соседних замеров |
| Задержка под нагрузкой ↓ и ↑ | пинги по WebSocket каждые 200 мс во время загрузки и отдачи |
| Bufferbloat (A+…F) | насколько задержка под нагрузкой выше, чем в покое |
| Потери пакетов, задержка и джиттер UDP | 200 пакетов через WebRTC DataChannel без повторов (`maxRetransmits: 0`) |
| Время до первого байта | Resource Timing запросов загрузки |
| Протокол, IPv4/IPv6, объём данных, длительность | — |
| Пригодность: стриминг 4K, игры, видеозвонки | по совокупности метрик |

История последних 30 тестов хранится в браузере пользователя.

## Запуск

```bash
cp .env.example .env     # по желанию: название, город сервера
docker compose up -d --build
```

Страница: `http://<сервер>:8080`. При первом старте сервер скачивает базы
DB-IP Lite (страна+город ~60 МБ, ASN ~5 МБ) в volume `geoip` и обновляет их раз в месяц;
пока база качается, на странице написано «база загружается…».

Нужно открыть порты: **8080/tcp** и **3479/udp** (UDP — только для теста потерь;
если он закрыт, тест пройдёт, потери будут «н/д»).

### HTTPS

```bash
DOMAIN=speed.example.com TRUST_PROXY=true docker compose --profile tls up -d --build
```

Caddy сам получит сертификат и даст HTTP/2 и HTTP/3. Порт 8080 в этом режиме стоит закрыть
файрволом: при `TRUST_PROXY=true` IP клиента берётся из `X-Forwarded-For`.

Если ставите за свой nginx — отключите буферизацию для `/api/`
(`proxy_buffering off; proxy_request_buffering off; client_max_body_size 0;`)
и проксируйте WebSocket на `/api/ws`, иначе тест будет мерить прокси, а не канал.

## Настройки (`.env`)

| Переменная | По умолчанию | |
|---|---|---|
| `HTTP_PORT` | 8080 | внешний порт |
| `SERVER_NAME` | Speedtest | название в шапке |
| `SERVER_LOCATION` | — | город сервера, показывается в карточке «Сервер» |
| `RTC_UDP_PORT` | 3479 | UDP-порт WebRTC |
| `RTC_PUBLIC_IP` | — | внешний IP для WebRTC; по умолчанию берётся из адреса, по которому зашёл браузер |
| `TRUST_PROXY` | false | доверять `X-Forwarded-For` (только за своим прокси) |
| `GEOIP_CITY` | true | `false` — только страна, без города (база меньше) |

## Устройство

```
браузер ──HTTP GET  /api/download?size=N ──▶ поток случайных байт из памяти
        ──HTTP POST /api/upload          ──▶ чтение в /dev/null
        ──WS        /api/ws              ──▶ эхо (пинг, пинг под нагрузкой)
        ──HTTP POST /api/rtc  (SDP)      ──▶ pion/webrtc, ICE-lite, один UDP-порт
        ◀═UDP DataChannel (эхо) ═════════▶
        ──HTTP GET  /api/info            ──▶ IP + DB-IP (страна, город, ASN)
```

- `main.go` — HTTP-сервер, загрузка/отдача, определение IP, статика (в памяти, заранее сжата gzip).
- `geoip.go` — скачивание и горячая замена баз DB-IP.
- `realtime.go` — WebSocket-эхо и WebRTC-эхо для теста потерь.
- `web/` — страница, встраивается в бинарник (`go:embed`).

Локально без Docker: `go run .` (переменная `DATA_DIR` — куда класть базы).

Геоданные: [IP Geolocation by DB-IP](https://db-ip.com), лицензия CC BY 4.0 — ссылка в подвале страницы обязательна.
